# workshop/ — the process shell

How this project gets made: `flows/` (baton flows) · `ideas/` · journals. It wraps, but is not
part of, the public **core** (the product). Keeps the core clean and the project self-contained —
it moves/extracts as one atomic unit.

- `flows/` — one dir per baton flow. Copy `_template/` to start. A flow builds something in the core.
- `ideas/` — concepts + sparks.

Gathered candidates (ripple harvests) land on a `skills/` shelf with provenance + license,
adopted only by a named act. See [baton](https://github.com/micaforge/baton-flow).
